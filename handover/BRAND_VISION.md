# Brand and Visual Direction

## Brand Positioning

> **InstaClient helps consult-driven local businesses stop losing appointments to missed calls and slow follow-up, and turn existing customers into more immediate revenue without spending more on ads.**

InstaClient is a direct, high-conviction growth system for businesses where a missed call or slow lead response can cost hundreds or thousands of dollars. The site should make the product feel like a practical revenue-recovery engine rather than generic “AI software.”

| Attribute | Direction |
|---|---|
| Audience | Med spas and cosmetic clinics, surgical and specialty practices, home-service businesses. |
| Promise | Faster response, recovered appointments, activated old leads, measurable revenue. |
| Tone | Direct, credible, outcome-led, calm, and specific. |
| Brand spelling | **InstaClient** — one word, capital **I** and **C**. |
| Logo lockup | “Insta” in black; “Client” in indigo blue. |
| Avoid | Unsubstantiated counts, exaggerated claims, generic “AI transformation” copy, and unexplained jargon. |

## Visual System

The established design is a bright, polished SaaS landing page. It uses a white background, deep near-black navy text, indigo-blue primary actions, and teal recovery/revenue accents. Typography is **Plus Jakarta Sans** for display headlines, **Inter** for body copy, and **JetBrains Mono** for numerical/stat treatment.

| System element | Existing pattern |
|---|---|
| Backgrounds | Predominantly white with very light cool-gray section backgrounds. |
| Primary color | Indigo/blue implemented via the project’s OKLCH utilities and gradient classes. |
| Accent color | Teal used for recovery figures, key icons, and supportive emphasis. |
| Cards | Rounded 2xl/3xl corners, light borders, subtle shadows; Convert can use a dark elevated treatment. |
| Hero | Asymmetrical copy-and-phone composition; static phone mockup must remain visible above the fold. |
| Motion | Gentle opacity/translate entrance motion; do not introduce distracting loops or large parallax. |
| Layout | Strong left-aligned section headers, controlled grid spacing, and readable mobile wrapping. |

## Copy Rules

The user prefers language that is clear enough to reverse-engineer. Specific claims should be plausible and framed in business-owner language. Use “leads” or “form leads,” never “inquiries,” unless quoting a user-provided source.

Avoid phrases such as “free trial.” A “free demo” remains intentional because the CTA calendar experience is positioned as a no-commitment diagnostic conversation.
